## Risks
- Scope creep → cut-line set on D1, enforced.
- Video/deck left to the end → drafts start D7, never later.
- AI-slop in deliverables → human pass on everything; read aloud.
- Deadline crunch → v1 submitted early; final hours are buffer only.

## Definition of done (submission)
